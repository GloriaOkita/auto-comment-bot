# 需求文档

## 项目背景

捣谷社区运营人员（税越及其同事）每天需人工完成以下重复工作：

1. 手动轮换登录多个虚拟账号
2. 逐个打开 Excel 表格中的帖子链接
3. 阅读帖子内容，人工撰写消费引导型评论
4. 发布评论
5. 在 Excel 表格对应位置标记完成

每日处理几十条内容，每个员工拥有 5 个虚拟账号，工作量繁琐且效率低下。

## 核心需求

### 功能需求

1. **账号管理**：支持从 Excel 文件批量导入多员工、多虚拟账号（用户名+密码），程序自动轮换调用
2. **自动读表**：读取本地 Excel 表格中的帖子链接，逐条打开并加载完整内容
3. **AI 评论生成**：识别帖子内容，调用公司内网 OpenAI API 生成自然真实、无模板套话、具备消费引导属性的评论
4. **自动发布**：每个账号对每个帖子发布不同评论，一个员工的全部账号评论完毕后自动切换到下一个员工
5. **完成标记**：评论发布成功后，在 Excel 对应员工列自动填写「1」

### 非功能需求

- **断点续跑**：中途关闭或断网后，下次启动从上次中断位置继续
- **安全防检测**：随机操作延迟（3-8秒），模拟真人节奏
- **错误容忍**：单条失败不影响整体流程，记录错误继续执行
- **进度可视化**：实时显示当前处理位置和日志

## 使用场景

1. 运营人员到达办公室，打开 Mac
2. 将当日帖子 Excel 放入指定位置
3. 确认账号 Excel 已更新（人员变动时更新）
4. 双击启动程序，点击"开始评论"
5. 全程自动运行，完成后查看日志确认
