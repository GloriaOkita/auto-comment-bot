# 自动评论机

Mac 桌面工具，为捣谷社区运营人员提供**全自动评论发布**功能。批量使用多虚拟账号，自动读取帖子链接，AI 识别帖子内容（文字+图片）生成自然真实的消费引导型评论并发布，最后在 Excel 表格中标记完成状态。

## 功能

- **自动登录** — 挨个调取虚拟账号 ID 和密码，全程无需手动输入
- **读取帖子** — 自动读取本地 Excel 表格中的帖子链接，逐条打开加载完整内容
- **图片识别** — AI 视觉模型识别帖子配图，结合文字内容生成精准评论
- **AI 生成评论** — 自然真实、无模板套话、多种风格轮换，像真人粉丝留言
- **自动发布** — 每个账号登录一次刷完所有帖子，然后自动切换下一个账号
- **表格标记** — 评论全部发布成功后，自动在 Excel 对应位置标记「1」
- **断点续跑** — 每步保存进度，不怕断网/崩溃
- **去重保护** — 发布前自动检查是否已评论过，避免重复

## 快速开始

### 环境要求

- macOS
- Python 3.9+
- 网络连接（公司内网 VPN）

### 安装

双击 `setup.command`，自动安装所有依赖。

或手动安装：

```bash
pip3 install playwright openpyxl requests
playwright install chromium
```

### 启动

双击 `自动评论机.command`，或终端运行：

```bash
python3 comment_app.py
```

### 配置

1. 复制 `config.example.json` 为 `config.json`，填入你的 API 地址和 Key
2. 准备账号 Excel（格式见下方）
3. 准备帖子表格（打标帖 Excel）

### 账号 Excel 格式

| 员工名 | 账号1_用户名 | 账号1_密码 | 账号2_用户名 | 账号2_密码 | ... |
|--------|-------------|-----------|-------------|-----------|-----|
| 张三   | zhangsan_v1 | 123456    | zhangsan_v2 | 123456    | ... |

### 运行

1. 点击「上传账号文件」选择账号 Excel
2. 点击「上传评论表格」选择帖子 Excel
3. 选择要处理的员工（或「全部」）
4. 点击「开始评论」
5. 运行日志实时显示进度

## 评论风格

每条帖子由多个账号分别评论，每个账号固定一种风格：

| 风格 | 特点 | 示例 |
|------|------|------|
| 简单直夸型 | 简短自然，像朋友圈评论 | 「好甜」「太会写了吧」 |
| 激动感叹型 | 情绪饱满，语气词开头 | 「啊啊啊甜死我了！！」 |
| 引用细节型 | 提到文中具体细节 | 「混天绫打死结……这是我们能看的吗」 |
| 提问互动型 | 像跟作者聊天 | 「老师也玩这个游戏吗」 |
| 俏皮调侃型 | 语气调皮，会开玩笑 | 「这哪是糖葫芦这是狗粮吧」 |

## 技术栈

| 层 | 技术 |
|----|------|
| 语言 | Python 3 |
| 浏览器自动化 | Playwright (Chromium) |
| Excel 读写 | openpyxl |
| AI 调用 | requests → OpenAI 兼容 API |
| GUI | tkinter |

## 注意事项

- **不要公开分享 `config.json` 和账号 Excel 文件**（含 API Key 和密码）
- 运行期间请保持 VPN 连接
- 首次使用建议用小范围数据测试评论质量
- 配置 `delay_min` / `delay_max` 可调整评论间隔，避免触发风控
